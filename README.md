# Northway Freight

Responsive landing page for a road freight company. I built it from a Figma design as a design-to-code practice project, using plain HTML, CSS and vanilla JavaScript.

**Live demo:** 

## Features

- Pixel-focused layout based on a Figma design
- Fully responsive: desktop, tablet and mobile
- Sticky header with a "Get a Quote" call to action
- Sections: hero, stats cards, intro, results with chart, features, CTA and footer
- CSS custom properties for colors and shared values
- CSS Grid and Flexbox layout
- Montserrat font

## Tech stack

- Figma
- HTML5
- CSS3 (Grid, Flexbox, media queries, custom properties)
- JavaScript (vanilla)

## Run locally

1. Clone the repository:
   ```
   git clone https://github.com/YOUR-USERNAME/northway-freight.git
   ```
2. Open the folder in VS Code.
3. Start it with the Live Server extension (right-click `index.html` → Open with Live Server), or just open `index.html` in a browser.

## Responsive breakpoints

| Device  | Width           |
|---------|-----------------|
| Desktop | above 1280px    |
| Small desktop | up to 1280px |
| Tablet  | up to 900px     |
| Mobile  | up to 768px     |
